# 课题四 运行说明

U 型截面多层钢筋笼 —— 捆扎交叉点深度视觉检测
系统源代码的运行说明文档（任务书上交清单第 2 项要求）。

---

## 1. 环境要求

- Python 3.8 及以上（开发环境为 3.12.7）
- 依赖库：

```bash
pip install opencv-python numpy scipy pillow
```

| 库 | 用途 | 开发环境版本 |
|---|---|---|
| opencv-python | 图像读写、形态学、Hough、连通域 | 5.0.0 |
| numpy | 数组运算 | 2.5.2 |
| scipy | 峰值检测（探针脚本用） | 1.18.0 |
| pillow | 结果图上的中文标注 | 12.3.0 |

说明：骨架化使用自实现的 Zhang-Suen 细化（`src/detect.py`），**不依赖 `cv2.ximgproc`**（该模块在标准 `opencv-python` 包中不存在），也不依赖 `scikit-image`。

在 Ubuntu 20.04 / 22.04 上：

```bash
sudo apt update && sudo apt install -y python3-pip
pip3 install opencv-python numpy scipy pillow
```

## 2. 数据准备

把数据目录放在工程根目录下，命名固定为 `任务书数据+代码`：

```
任务书数据+代码/
├── station_1_output_image_left.png     灰度图  1080 x 1440（竖构图）
├── station_1_output_depth_raw.tif      深度图  1440 x 1080（横构图）float32，单位米
├── station_2_...
└── ...（共 10 个工位）
```

数据格式要求：
- 灰度图为 8 位单通道 png；
- 深度图为 float32 的 tif，**单位是米**，无回波处为 `NaN`；
- 灰度图与深度图尺寸互为转置，程序内部会**自动把深度图逆时针旋转 90°** 完成对齐，不需要预处理。

## 3. 运行方法

```bash
cd <工程根目录>

# 阶段一：数据读取 + 灰度增强 + 深度分层，输出分层对照图
python run.py --all --stage preview

# 阶段二：交叉点检测，输出标注图（筋轴线 + 三类交叉点）
python run.py --all --stage detect

# 阶段三：输出交付用的一页式结果图 + 交叉点坐标 + 汇总表
python run.py --all --stage report

# 只跑指定工位
python run.py --stations 1 6 --stage report
```

全部结果写入 `outputs/`。

常用参数：

| 参数 | 说明 |
|---|---|
| `--stations 1 6` | 指定工位编号 |
| `--all` | 处理数据目录里的全部工位 |
| `--stage` | `preview` / `detect` / `report`，默认 `preview` |
| `--data-dir` | 数据目录，默认 `任务书数据+代码` |
| `--out-dir` | 输出目录，默认 `outputs` |
| `--split-mm` | 手动指定顶层/下层深度分界（调试用）。**默认自动定界**，不建议写死 |

## 4. 输出说明

| 文件 | 内容 |
|---|---|
| `station_N_result.png` | **交付用的一页式结果图**。四格：①增强灰度图上的检测结果（含图例）②深度分层 ③顶层掩膜+骨架+筋轴线 ④统计信息 |
| `station_N_points.csv` | 保留的交叉点坐标 `point_id, x_px, y_px, z_mm` |
| `station_N_points.json` | 保留的交叉点坐标，每行一个 `[x, y]`（任务书建议格式） |
| `station_N_rejected.json` | 被筛掉的两类点：`lower`（下层交叉点）与 `clutter`（虚假干扰点） |
| `station_N_detect.png` | 检测标注图（调试用，无图例） |
| `station_N_preview.png` | 分层对照图（调试用） |
| `summary.csv` | 全部工位的统计汇总 |

结果图配色：

- **红色**实心点 = 保留的顶层交叉点
- **蓝色**实心点 = 被深度阈值筛掉的下层交叉点
- **橙色**实心点 = 被判为虚假干扰点的位置
- **品红**直线 = 顶层横筋轴线
- **青色**直线 = 顶层竖筋轴线
- **绿色**细线 = 顶层骨架

## 5. 算法流程

```
灰度图(png) ──┐
              ├─► 深度图逆时针旋转 90° 与灰度图对齐
深度图(tif) ──┘        │
                       ├─► CLAHE 光照校正（原图极暗，均值仅 16.7）
                       │
                       └─► 深度直方图空段自动定界 ──► 顶层掩膜 / 下层掩膜
                                  │
        顶层掩膜 ──► 闭运算补缺口 ──► Zhang-Suen 骨架化 ──► 去骨架分叉点
                                  │
                                  └─► HoughLinesP ──► 按族参数化聚类 ──► PCA 精修
                                          （横筋 y=ax+b，竖筋 x=ay+b）
                                  │
                                  └─► 筋条自检：支撑像素数/跨度，滤掉弱线
                                  │
        横筋轴线 × 竖筋轴线 ──► 两两求交 ──► 交叉点去重
                                  │
                                  └─► 三分类：
                                        深度在顶层 且 两条筋都够长 且 局部有连续支撑
                                                            且 四周不是实心块  → 保留
                                        深度落在下层                                 → 下层点
                                        形状/连续性不像钢筋、或压在实心杂物上        → 虚假干扰点
```

各步骤的实测依据（投影关系、深度分层裕度、筋条走向、自检指标等）见 `docs/交接文档.md` 第 4 节。

### 5.1 结果自检（建议运行）

```bash
python tools/probe/audit_junctions.py          # 交叉点完备性审计表
python tools/probe/audit_junctions.py --sheet  # 另存待复查点的放大图
```

审计口径：把“顶层横筋 × 顶层竖筋两两求交、且交厹落在两条筋实测跨度内”
当作期望交叉点，与最终保留点比对，给出完备率、多余点及每个剔除点的原因。
当前 10 站结果：期望 295 个，保留 293 个，多余 0 个，完备率 99.3%；
2 个剔除点均已逐个查明（见交接文档 F15）。

## 7. 常见问题

**Q：报错 `深度图读取失败` 或 `cv2.imread` 返回 None？**
`cv2.imread` 在 Windows 下无法读取含中文的路径。程序内部统一使用 `src/imgio.py::imread_any`（`np.fromfile` + `cv2.imdecode`）规避，请勿改用 `cv2.imread`。

**Q：PowerShell 里中文输出是乱码？**
那是控制台代码页问题，不影响写入文件的内容。

**Q：某个工位分层不对？**
先跑 `--stage preview` 看该工位的深度直方图是否两簇分离。程序按"第一段足够宽的空白"自动定界；如果打印出"可分离=False"，说明该工位两层在深度上粘连，需要人工介入。

**Q：结果图上的中文变成方框？**
说明系统里没有找到中文字体。程序按 `msyh.ttc → simhei.ttf → simsun.ttc → NotoSansCJK → wqy-zenhei` 顺序查找，可自行在 `src/viz.py::_FONT_CANDIDATES` 里补充字体路径。
