# 演示视频脚本（1 分 30 秒左右）

任务书上交清单最后一项要求 1–2 分钟的演示视频。下面是一份可直接照做的分镜，
所有命令都能在 Ubuntu 虚拟机里跑，录屏建议在虚拟机内完成（顺便就是复现证据）。

---

## 录屏准备

先在虚拟机里把窗口调成 1600×900 以上，终端字号调到 16–18（录像里要能看清）。
录屏三种方式任选：

```bash
# 方式一：GNOME 自带（Ubuntu 22.04）
#   按 Ctrl+Alt+Shift+R 开始 / 结束，文件落在 ~/Videos

# 方式二：ffmpeg 抓屏（先装：sudo apt install -y ffmpeg）
ffmpeg -f x11grab -y -video_size 1920x1080 -framerate 25 -i :0.0 demo.mp4

# 方式三：OBS Studio（图形界面，可选装）
```

## 录制小贴士

- 命令先跑一遍确认无误，再正式录，避免等编译。
- `python run.py --all --stage report` 全站约 40 秒，录像时可以只录 `--stations 1`，
  再口头说明"全部 10 站结果已批量生成在 outputs/"。
- 终端里中文若显示成方块，先 `sudo apt install -y fonts-noto-cjk`；
  结果图里的中文由 PIL 渲染，同一套字体要求。
